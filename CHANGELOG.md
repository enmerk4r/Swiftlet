# Changelog

## 0.4.0 - 2026-11-18

- **Grasshopper 2:** native version for Rhino 9 with all 115 components. One `swiftlet` package covers Rhino 8 (Grasshopper 1) and Rhino 9 (both).
- Grasshopper 1 definitions convert to native Grasshopper 2 components.
- Every example has a Grasshopper 2 `.ghz` file.
- Security: ImageSharp 3.2.0.
- Fixes for servers, MCP, OAuth, WebSockets, file transfers and XML in both versions.
- Not yet tested inside Rhino for Mac.
